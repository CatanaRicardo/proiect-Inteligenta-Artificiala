# proiect-Inteligenta-Artificiala
Un sistem de inferență predicativă prin raționament înainte, utilizat pentru demonstrarea a două teoreme matematice (un nr par are pătratul par | un triunghi echilateral este isoscel”). Fiecare afirmație va fi tratată ca un predicat, iar prin aplicarea regulilor de inferență se vor genera consecințele logice necesare până la obținerea concluziei.
